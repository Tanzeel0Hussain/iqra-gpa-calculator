About This Tool

A focused academic planning utility for the Iqra University student community.

What is Iqra GPA Calculator?

The Iqra GPA Calculator is an independent student-built utility designed for Iqra University students. It simplifies semester GPA and cumulative CGPA calculations, supports legacy and revised grading schemes, and keeps draft data locally in the browser for convenient academic planning.

Multiple Grading Schemes

Switch between legacy undergraduate, revised undergraduate and revised graduate grade-point scales.

PDF and Print

Generate an unofficial planning report or print your calculation for your own academic records.

Responsive Interface

The calculator is optimized for phones, tablets and desktop browsers with a clean student-focused layout.

Local Privacy

Calculator drafts are stored in your own browser using local storage and are not sent to a project server.
